# FMM26-inspired Football Manager Web Game

A Vite + React prototype of the football-management game UI we designed.

## Run in VS Code

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Make sure Node.js 18+ is installed.
4. Open the VS Code terminal.
5. Run:

```bash
npm install
npm run dev
```

6. Open the local URL Vite prints, normally `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Important

This is a **working frontend prototype**, not yet a full production football simulation. The next engineering stage is to connect the UI to a real game engine/data model, persistence/database, match simulation, transfer AI, scouting AI, player development, fixtures, competitions, finances, and save/load systems.
